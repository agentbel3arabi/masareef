# Feature: Financial Reports & Export

## Purpose
Users need to generate, view, and export financial reports for personal review, tax preparation, family discussions, and record-keeping. Reports aggregate data across accounts, categories, and time periods into structured summaries that go beyond what the dashboard shows.

## Report Types

### 1. Income & Expense Report
Monthly or custom date range breakdown of all income and expenses.

**Sections:**
- Summary: total income, total expenses, net (surplus/deficit)
- Income by category: table with amount + percentage
- Expenses by category: table with amount + percentage
- Monthly trend: income vs expense per month within range
- Top 10 merchants/descriptions by spend

**Filters:** date range, account(s), category(ies), currency

### 2. Category Deep Dive
Single category analysis over time.

**Sections:**
- Monthly spend trend for the selected category
- Average monthly spend
- Highest and lowest months
- All transactions in this category (paginated)
- Comparison: this category vs same period last year (if data available)

**Filters:** category, date range, account(s)

### 3. Net Worth Report
Point-in-time or historical net worth composition.

**Sections:**
- Current net worth breakdown: accounts, assets, debts
- Per-currency breakdown before conversion
- Net worth timeline chart (same as dashboard but exportable)
- Asset appreciation/depreciation summary
- Debt payoff progress summary

**Filters:** date (point-in-time snapshot), base currency

### 4. Debt Summary Report
All debts with payment history and projections.

**Sections:**
- Active debts table: name, type, remaining, monthly payment, payoff date
- Payment history per debt
- Total interest paid (bank loans)
- P2P balance summary per person
- Installment utilization per credit card

**Filters:** debt type, status, date range

### 5. Account Statement
Bank-statement-style report for a single account.

**Sections:**
- Opening balance at start of period
- All transactions chronologically
- Running balance after each transaction
- Closing balance at end of period
- Summary: total debits, total credits, net change

**Filters:** account, date range

### 6. Asset Report
Portfolio overview of all assets.

**Sections:**
- Asset list with current value, purchase price, ownership cost, operating cost, ROI
- Value by asset type (pie chart data)
- Top appreciating and depreciating assets
- Total portfolio value in base currency

**Filters:** asset type, date range

### 7. Gam3eya Report
Summary of all Gam3eya activity.

**Sections:**
- Active Gam3eyas: name, progress, net position, next payment
- Completed Gam3eyas: final summary
- Total contributed vs total received across all Gam3eyas
- Calendar view of upcoming payments

**Filters:** status (active/completed)

## Export Formats

| Format | Use Case | Implementation |
|--------|----------|---------------|
| PDF | Formal reports, printing, sharing | Server-side generation via WeasyPrint or reportlab |
| Excel (.xlsx) | Data analysis, custom manipulation | openpyxl with formatted sheets |
| CSV | Raw data import into other tools | Standard CSV with UTF-8 BOM for Excel compatibility |

### PDF Styling
- Masareef branding (logo, colors)
- RTL layout when locale is Arabic
- Tables with alternating row colors
- Charts embedded as images (Plotly server-side rendering via kaleido)
- Page headers: report name, date range, generation date
- Page footers: page numbers, "Generated by Masareef"

### Excel Structure
- Summary sheet with key metrics
- Detail sheet(s) with transaction-level data
- Formatted headers, number formatting for currency columns
- Sheet name in Arabic when locale is Arabic

## API Endpoints

### `POST /api/v1/reports/generate`
Generate a report. Returns report data for on-screen viewing.

**Request:**
```json
{
  "type": "income_expense",
  "date_from": "2026-01-01",
  "date_to": "2026-03-31",
  "account_ids": null,
  "category_ids": null,
  "currency": "EGP"
}
```

**Response:** Report-type-specific JSON (see report type sections above for structure).

### `POST /api/v1/reports/export`
Generate and export a report as a file.

**Request:**
```json
{
  "type": "income_expense",
  "format": "pdf",
  "locale": "ar",
  "date_from": "2026-01-01",
  "date_to": "2026-03-31",
  "account_ids": null,
  "category_ids": null,
  "currency": "EGP"
}
```

**Response:** File download (Content-Disposition: attachment).

For large reports, returns a job ID for async generation:
```json
{
  "data": {
    "job_id": "uuid-...",
    "status": "processing",
    "estimated_seconds": 10
  }
}
```

### `GET /api/v1/reports/jobs/{job_id}`
Check status of async report generation.

**Response:**
```json
{
  "data": {
    "job_id": "uuid-...",
    "status": "completed",
    "download_url": "/api/v1/reports/download/uuid-...",
    "expires_at": "2026-03-23T09:00:00Z"
  }
}
```

Generated files stored in Supabase Storage with expiring URLs (1 hour default).

> **Async job implementation:** Report jobs are tracked in the `report_jobs` database table (see [02-data-models.md](../02-data-models.md) → Async Jobs section). The job record stores `status`, `download_url`, `error_message`, `completed_at`, and `expires_at`. Background work is executed via `asyncio.create_task()` or a task queue. Using the database (vs. in-memory dict) ensures jobs survive server restarts and supports horizontal scaling across multiple backend instances.

### `GET /api/v1/reports/download/{job_id}`
Download a generated report file.

## Scheduled Reports (Future Enhancement)
Users can schedule recurring report generation:
- Weekly spending summary → emailed every Monday
- Monthly income/expense report → emailed on the 1st
- Uses the notification system (email, Telegram) for delivery

## Acceptance Criteria
- [ ] All 7 report types generate correct data from the query filters
- [ ] Reports respect household scope (RLS) — never leak cross-household data
- [ ] PDF export renders correctly in both LTR (English) and RTL (Arabic)
- [ ] PDF includes embedded Plotly charts as images
- [ ] Excel export has formatted headers, currency number formatting, named sheets
- [ ] CSV export includes UTF-8 BOM for Excel compatibility
- [ ] Multi-currency amounts converted to selected base currency in reports
- [ ] Large reports (>5,000 transactions) use async generation with job polling
- [ ] Generated files stored in Supabase Storage with expiring download URLs
- [ ] Date range filters work correctly across all report types
- [ ] Account and category filters narrow results as expected
- [ ] Account statement shows running balance after each transaction
- [ ] Asset report shows ownership cost separate from operating cost
- [ ] P2P balance summary in debt report shows per-person per-currency net
