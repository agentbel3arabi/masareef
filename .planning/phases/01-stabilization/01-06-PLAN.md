**Step 1: Update `require_role()` error format in `backend/app/dependencies_rbac.py`**

Per D-12, change the HTTPException detail from a plain string to the error envelope format:

Current (line ~50):
```python
raise HTTPException(
    status_code=status.HTTP_403_FORBIDDEN,
    detail=f"Role '{role.value}' is not permitted for this action",
)
```

Change to:
```python
required = ", ".join(r.value for r in allowed)
raise HTTPException(
    status_code=status.HTTP_403_FORBIDDEN,
    detail={
        "error": {
            "code": "FORBIDDEN",
            "message": f"Requires {required} role",
        }
    },
)
```
