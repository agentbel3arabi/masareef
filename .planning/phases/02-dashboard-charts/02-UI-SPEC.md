## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gap within stat card trend line, legend dot spacing |
| sm | 8px | Gap between paired bar chart columns, inner stat card padding between rows, time range toggle vertical padding (`py-2`) |
| md | 16px | Card internal padding, chart container padding, gap between legend items, time range toggle horizontal padding (`px-4`) |
| lg | 24px | Gap between stat cards (grid gap), gap between chart sections |
| xl | 32px | Chart area internal padding (`p-8` = 32px) |
| 2xl | 48px | Page-level vertical spacing between major sections (stat cards -> charts -> bottom widgets) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Chart SVG area height: 256px (`h-64`) for all chart containers on desktop

Source: Existing dashboard page uses `space-y-6` (24px), `gap-4` (16px), `gap-6` (24px). Stitch design uses `p-6` (24px) for stat cards, `p-8` (32px) for chart containers.

## Typography

| Role | Size | Weight | Line Height | Usage in this phase |
|------|------|--------|-------------|---------------------|
| Body | 14px (`text-sm`) | 400 (normal) | 1.5 | Chart legends, upcoming payment descriptions, secondary labels, currency suffix adjacent to display values (`text-muted-foreground`) |
| Label | 12px (`text-xs`) | 400 (normal) | 1.5 | Stat card labels, chart axis labels, category percentages, time range toggle text (inactive) |
| Heading | 20px (`text-xl`) | 700 (bold) | 1.2 | Chart section titles ("Net Worth Trajectory", "Cash Flow", "Monthly Allocation") |
| Display | 24px (`text-2xl`) | 700 (bold) | 1.2 | Stat card primary values (formatted money amounts) |

Additional constraints:
- Trend delta text: 12px (`text-xs`), weight 700 (bold), color determined by direction (green up / red down)
- Time range toggle active button: 12px (`text-xs`), weight 700 (bold), `text-primary`
- Time range toggle inactive button: 12px (`text-xs`), weight 400 (normal), `text-muted-foreground`
- Time range toggle button padding: `py-2 px-4` (8px vertical, 16px horizontal)

Source: Stitch design uses `text-2xl font-black` for values, `text-xl font-bold` for headings. Collapsed to 2 weights: 400 (normal) for body/secondary text, 700 (bold) for all emphasis (display values, headings, active states, trend deltas).

## Interaction Contract

### Time Range Toggle (D-05)
- **Trigger:** Click any of 1M, 3M, 6M, 1Y, All buttons
- **Affected charts:** Net Worth Timeline AND Income vs Expenses bar chart
- **NOT affected:** Spending by Category donut (always current month)
- **Visual:** Active button gets `bg-card shadow-sm rounded-md text-primary font-bold` styling. Inactive gets transparent background, `text-muted-foreground font-normal`.
- **Button sizing:** `py-2 px-4` (8px vertical, 16px horizontal), `text-xs` (12px)
- **Default:** 6M
- **State:** Local component state (`useState`). Not persisted.
- **Data fetching:** Re-fetches dashboard endpoints with `months` param matching selected range (1, 3, 6, 12, or omit for all).

### Compare Toggle (D-07)
- **Trigger:** Click toggle switch on Income vs Expenses chart
- **Effect:** When enabled, shows DeltaSummaryCard above bar chart with: `Current month: X EGP | Previous month: Y EGP | Delta: +/-Z EGP (+/-N%)`
- **Visual:** Current month bars at full opacity, previous month bars at 40% opacity side-by-side
- **Default:** Off
- **State:** Local component state

### Donut Slice Click (D-06)
- **Trigger:** Click any slice in the donut chart
- **Action:** `router.push('/transactions?category={category_id}&period=month')`
- **Visual:** Slice highlights on hover with slight pull-out effect (Plotly `pull` config)
- **Feedback:** Cursor changes to pointer on hover

### Base Currency Selector (D-12)
- **Trigger:** Select a currency from dropdown
- **Affected:** All stat cards + all charts re-fetch with new `base_currency` param
- **Persistence:** Writes to household settings via API call (optimistic update)
- **Options:** From household's configured currencies (at minimum: EGP, USD, SAR)
- **Default:** Household's current `base_currency` setting

### Stat Card Trends (D-11)
- **All 4 stat cards** show month-over-month delta
- **Format:** `[arrow] [absolute delta] ([percentage]%)`
- **Arrow:** Up arrow (`TrendingUp` icon) for increase, down arrow (`TrendingDown` icon) for decrease
- **Color:** Contextual — for Net Worth, up = green (good). For Spending, down = green (spending less = good). For Debts, down = green (less debt = good). For Upcoming, neutral.

## Plotly Chart Styling Contract

All Plotly charts MUST use these configuration values for visual consistency:

### Global Plotly Layout Config

```typescript
const baseLayout: Partial<Plotly.Layout> = {
  font: {
    family: "Inter, Noto Sans Arabic, system-ui, sans-serif",
    size: 12,
    color: "hsl(215.4 16.3% 46.9%)", // --muted-foreground light
  },
  paper_bgcolor: "transparent",
  plot_bgcolor: "transparent",
  margin: { t: 8, r: 16, b: 40, l: 48 },
  showlegend: false, // legends are custom HTML, not Plotly-rendered
  hoverlabel: {
    bgcolor: "hsl(0 0% 100%)", // --card light
    bordercolor: "hsl(214.3 31.8% 91.4%)", // --border light
    font: {
      family: "Inter, Noto Sans Arabic, system-ui, sans-serif",
      size: 13,
      color: "hsl(222.2 47.4% 11.2%)", // --foreground light
    },
  },
};
```

Dark mode: Detect via `document.documentElement.classList.contains('dark')` and swap `hoverlabel.bgcolor`, `hoverlabel.font.color`, and `font.color` to dark mode CSS variable values.

### Global Plotly Config

```typescript
const baseConfig: Partial<Plotly.Config> = {
  displayModeBar: false,
  responsive: true,
  scrollZoom: false,
  staticPlot: false, // allow hover interactivity
};
```

### Net Worth Timeline Specifics
- Type: `scatter` with `fill: 'tozeroy'`
- Line: `color: "hsl(199.4 95.5% 73.9%)"`, `width: 3`, `shape: 'spline'`
- Fill: `fillcolor: "hsla(199.4, 95.5%, 73.9%, 0.15)"`
- Debt overlay: `scatter` line, `dash: 'dash'`, `color: "hsl(0 84.2% 60.2%)"`, `width: 2`
- X-axis: month labels (abbreviated, e.g., "Jan", "Feb"). Gridlines hidden.
- Y-axis: Amount in base currency. 4 horizontal gridlines at `color: "hsla(222.2, 47.4%, 11.2%, 0.05)"`
- Hover template: `"<b>%{x}</b><br>Net Worth: %{y:,.0f} EGP<extra></extra>"`

### Income vs Expenses Specifics
- Type: `bar` with `barmode: 'group'`
- Income bars: `marker.color: "hsl(142.1 76.2% 36.3%)"` (current month), `"hsla(142.1, 76.2%, 36.3%, 0.2)"` (other months)
- Expense bars: `marker.color: "hsl(0 84.2% 60.2%)"` (current month), `"hsla(0, 84.2%, 60.2%, 0.2)"` (other months)
- Bar corner radius: `marker.line.width: 0`, rounded top via Plotly `marker.cornerradius` if available, else accept square tops
- X-axis: month abbreviations
- Y-axis: amounts, gridlines hidden
- Hover template: `"<b>%{x}</b><br>%{data.name}: %{y:,.0f} EGP<extra></extra>"`
- Legend: Custom HTML below chart (green dot + "Income", red dot + "Expense")

### Spending by Category Donut Specifics
- Type: `pie` with `hole: 0.6`
- Colors: From API `category.color` field. Fallback sequence: chart-1 through chart-5.
- Text inside hole: Total amount (custom annotation overlay, not Plotly text)
- Pull on hover: `pull: 0.03` for hovered slice
- Top 8 categories shown individually, rest grouped as "Other"
- "Other" slice color: `"hsl(215.4 16.3% 46.9%)"` at 50% opacity
- Hover template: `"<b>%{label}</b><br>%{value:,.0f} EGP (%{percent})<extra></extra>"`
- Legend: Custom HTML grid (2 columns) below donut showing: color dot + category name + percentage
- Click handler: `plotly_click` event fires `router.push('/transactions?category=${point.customdata}&period=month')`
